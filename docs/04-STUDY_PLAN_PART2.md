### Day 31 - 缓存实现

**学习时间**: 3 小时

**内容**:
1. Redis 集成 (1 小时)
2. 缓存策略 (1 小时)
3. 缓存失效处理 (1 小时)

**实践任务**:
```typescript
// Redis 缓存
import { Redis } from 'ioredis'

const redis = new Redis()

// 缓存中间件
app.derive(async ({ request }) => {
  const key = `cache:${request.url}`
  const cached = await redis.get(key)
  
  if (cached) {
    return { cache: JSON.parse(cached) }
  }
  
  return { cache: null }
})
```

3. Docker Compose (1 小时)

**实践任务**:
```dockerfile
# Dockerfile
FROM oven/bun:1

WORKDIR /app
COPY package.json bun.lockb ./
RUN bun install --production

COPY . .
EXPOSE 3000

CMD ["bun", "run", "src/index.ts"]
```

### Day 36 - CI/CD 流程

**学习时间**: 3 小时

**内容**:
1. GitHub Actions (1 小时)
2. 自动化测试 (1 小时)
3. 自动化部署 (1 小时)

**实践任务**:
```yaml
# .github/workflows/deploy.yml
name: Deploy

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: oven-sh/setup-bun@v1
      - run: bun install
      - run: bun test
      - run: bun run build
```

## 学习建议

### 1. 循序渐进

不要跳步学习，每个知识点都要理解透彻再进行下一步。

### 2. 多动手实践

光看不练是学不会的，每个案例都要亲手敲一遍代码。

记录重要知识点和遇到的问题，方便日后查阅。

遇到问题先搜索，解决不了可以在社区提问。
