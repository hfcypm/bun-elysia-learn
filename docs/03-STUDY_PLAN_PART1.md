### Day 1 - 环境搭建和 Hello World

**学习时间**: 2 小时

**内容**:
1. 安装 Bun 运行时 (30 分钟)
2. 创建第一个 Elysia 项目 (30 分钟)
3. 理解 Elysia 基本结构 (30 分钟)
4. 运行 Hello World 示例 (30 分钟)

**实践任务**:
```bash
# 1. 安装 Bun
curl -fsSL https://bun.sh/install | bash

# 2. 创建项目
bun init elysia-hello
cd elysia-hello
bun add elysia
```

**代码练习**:
```typescript
import { Elysia } from 'elysia'

new Elysia()
  .get('/', () => 'Hello Elysia!')
  .listen(3000)
```

**检查清单**:
- [ ] 成功安装 Bun
- [ ] 项目能够正常运行
- [ ] 能够访问 http://localhost:3000

### Day 2 - 路由和参数处理

**学习时间**: 2.5 小时

**内容**:
1. 路径参数 (45 分钟)
2. 查询参数 (45 分钟)
3. 请求头处理 (30 分钟)
4. 响应类型 (30 分钟)

**实践任务**:
```typescript
// 路径参数
.get('/users/:id', ({ params }) => {
  return { id: params.id }
})

// 查询参数
.get('/search', ({ query }) => {
  return { keyword: query.keyword }
})

// 请求头
.get('/headers', ({ request }) => {
  return {
    userAgent: request.headers.get('user-agent')
  }
})
```

**练习**:
- [ ] 创建个性化问候接口 `/hello/:name`
- [ ] 创建搜索接口，支持多参数查询
- [ ] 读取并返回请求头信息
